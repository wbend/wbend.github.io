What is "Trail Breaking"?

When sanctions are applied to cryptocurrency wallets, investigators can trace funds on the blockchain. To evade this, operators use techniques to "break the trail":

  • Wallet Succession: Stop using Wallet A, start using Wallet B with similar volume
  • Hub Mixing: Route funds through central "hub" wallets that obscure origin/destination
  • Burn/Mint: Destroy tokens in one wallet, create fresh tokens in another (breaks on-chain link)

This tool detects these patterns by analyzing temporal correlations, volume matching, and shared counterparties.
